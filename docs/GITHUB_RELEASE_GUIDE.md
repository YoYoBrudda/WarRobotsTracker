# GitHub release guide for the creator

## Recommended repo name

`war-robots-screenshot-tracker`

## Upload these files

Upload the entire project folder to GitHub.

## Suggested release title

`War Robots Screenshot Tracker v2.0 - No-code GUI version`

## Suggested release description

This version adds a beginner-friendly desktop app. Users can choose their screenshot folder, enter their in-game name, process screenshots, auto-watch for new screenshots, and open their CSV/HTML summary without editing code.

Known limitation: users still need Python and Tesseract OCR installed. Future versions may be packaged as a standalone `.exe`.

## What to tell viewers

Download the ZIP from the GitHub release, extract it, install Python and Tesseract OCR, then double-click the launcher for your operating system.
